# Running the scorer's kernels without a GPU

`harness.cu`, generated by `generate_harness.py`, performs the multiply and the reduction that
`CudaMatrixDotProductScorer` performs and checks what they keep against a reference computed on
the host. The reduction is taken from the Java rather than copied, so the two cannot drift.
Generate it, then compile and run it wherever a GPU is:

```bash
python3 generate_harness.py
nvcc -DUSE_CUBLAS -gencode arch=compute_80,code=compute_80 -o harness harness.cu -lcublas
./harness
```

Without `-DUSE_CUBLAS` the library multiply is replaced by one written in the harness, producing
what the `cublasSgemm` call is specified to produce. That form exercises the reduction alone.

## GPGPU-Sim cannot stand in for a GPU here

GPGPU-Sim 4.2 was built against CUDA 12.6 and run against both forms on its A100 configuration.
Neither completes, for two reasons that are properties of the simulator rather than of this
code.

**It does not implement the synchronising warp shuffle.** `__shfl_down_sync` returns zero to
every lane, which a twelve-line program reducing a warp to its largest lane confirms: it yields
zero where it should yield thirty-one. The reduction is built on that instruction, so under the
simulator it produces a row number and a similarity belonging to different rows. That result is
an artifact and says nothing about the kernel. CUDA 12 removed the older `__shfl_down`, so there
is no substitute to fall back to.

**It cannot load a current cuBLAS.** The simulator reads kernels only from a statically linked
library, which works as far as parsing cuBLAS's own `sgemm`, and then aborts on a device
function it cannot resolve, `cuda_reorder_imma_filter`. Pruning the library to one architecture
with `nvprune` gets past an earlier assertion in its PTX parser but not past this. The
limitation with precompiled NVIDIA libraries is one the maintainers describe.

A simulator would not settle the bindings in any case. The scorer reaches CUDA through JavaCPP
from a JVM, and the simulator substitutes a runtime library for a natively linked program.
Verifying this scorer needs a GPU.
